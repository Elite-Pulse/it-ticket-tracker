IT Ticket Tracker

Track, resolve and report on IT support tickets - configurable, automated, and self-contained.

🗂 Fully configurable

Stages, Types, Categories, Priorities and Reporters are all managed from Configuration - no fixed lists, no code changes needed as your process evolves.

📋 Kanban that works like Tasks

Drag tickets between stages, add/rename/reorder stages on the fly, mark favorites, and see colored priority/category tags at a glance.

📊 Reports on demand or on autopilot

Generate PDF and Excel reports with a filter dialog, or schedule automatic emails - daily, weekly, bi-weekly, monthly or yearly - with a full audit history of every send.

🔐 Three access levels

  • Own Tickets - see and edit only tickets assigned to them
  • All Tickets - see and edit every ticket (no delete)
  • Administrator - full access, configuration, auto-mailing

⏱ Automatic calculations

  • Resolution Time, computed from Date Opened / Date Closed
  • ISO-8601 Week Number, computed from Date Opened
  • Optional auto-generated Ticket IDs with a configurable prefix
